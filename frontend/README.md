# frontend/

Next.js (App Router, TypeScript estricto, Tailwind, shadcn/ui, TanStack Query). **Vacío en la Fase 0.5**: se crea en la Fase 1.

- Solo UI: sin secretos ni lógica de negocio (ADR-003).
- Rutas de tenant bajo `/o/[orgSlug]/…` (D3).
- Cliente de API generado desde OpenAPI en `src/lib/api/` (no editar a mano).
